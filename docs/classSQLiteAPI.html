Detailed Description

Adaptee participant in the Adapter design pattern for local SQLite.

Encapsulates low-level <sqlite3.h> file connection handling and prepared statement execution (sqlite3_prepare_v2, sqlite3_bind_text, sqlite3_step) on a local .db file
