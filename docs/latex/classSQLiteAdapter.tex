\doxysubsection{Detailed Description}
Adapter in the Adapter pattern and Concrete\+Strategy in the Strategy pattern for SQLite. 

Adapts the low-\/level \doxylink{classSQLiteAPI}{SQLite\+API} (Adaptee) to the \doxylink{classExternalDatabase}{External\+Database} (Target) interface so \doxylink{classDatabaseObserver}{Database\+Observer} can persist and retrieve workflow records locally in a {\ttfamily .db} file
