\doxysubsection{Detailed Description}
A Concrete Strategy/\+Adapter that sends emails via the Resend REST API. 

Implements the \doxylink{classEmailTransport}{Email\+Transport} interface. Handles bearer token authentication and translates the payload into Resend\textquotesingle{}s expected JSON format.
