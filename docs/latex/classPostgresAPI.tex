\doxysubsection{Detailed Description}
Adaptee participant in the Adapter design pattern for Cloud Postgre\+SQL. 

Encapsulates low-\/level libpq connection management and parameterized SQL execution ({\ttfamily PQexec\+Params}) for communicating with a remote Postgre\+SQL server
