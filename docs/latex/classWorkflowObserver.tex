\doxysubsection{Detailed Description}
Abstract Observer participant in the Observer design pattern. 

Defines the notification interface for objects that should be notified whenever a \doxylink{classWorkflowSubject}{Workflow\+Subject} (a \doxylink{classWorkComponent}{Work\+Component}) changes its state or payload data
