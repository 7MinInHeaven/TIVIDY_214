\doxysubsection{Detailed Description}
Adaptee participant in the Adapter design pattern for local SQLite. 

Encapsulates low-\/level {\ttfamily \texorpdfstring{$<$}{<}sqlite3.\+h\texorpdfstring{$>$}{>}} file connection handling and prepared statement execution ({\ttfamily sqlite3\+\_\+prepare\+\_\+v2}, {\ttfamily sqlite3\+\_\+bind\+\_\+text}, {\ttfamily sqlite3\+\_\+step}) on a local {\ttfamily .db} file
