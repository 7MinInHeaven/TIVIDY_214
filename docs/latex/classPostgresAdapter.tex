\doxysubsection{Detailed Description}
Adapter in the Adapter pattern and Concrete\+Strategy in the Strategy pattern for Postgre\+SQL. 

Adapts the low-\/level \doxylink{classPostgresAPI}{Postgres\+API} (Adaptee) to the \doxylink{classExternalDatabase}{External\+Database} (Target) interface so \doxylink{classDatabaseObserver}{Database\+Observer} can persist and retrieve workflow records in Neon Cloud Postgre\+SQL
