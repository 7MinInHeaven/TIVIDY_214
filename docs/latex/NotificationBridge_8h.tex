\doxysubsection{Detailed Description}
Defines the Bridge pattern for the notification subsystem. 

This file contains the Abstractions (\doxylink{classNotification}{Notification}, \doxylink{classResultNotice}{Result\+Notice}) and the Implementors (\doxylink{classNotificationChannel}{Notification\+Channel}, \doxylink{classEmailChannel}{Email\+Channel}) that decouple the message content from the delivery mechanism.
