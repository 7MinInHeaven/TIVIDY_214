\doxysubsection{Detailed Description}
The Adaptee in the Adapter Pattern for Mailjet. 

Provides a thin wrapper around libcurl to handle Basic Authentication and POST requests. Used internally by the \doxylink{classMailjetEmailAdapter}{Mailjet\+Email\+Adapter}.
