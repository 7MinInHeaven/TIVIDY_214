\doxysubsection{Detailed Description}
Concrete Observer in the Observer Pattern. 

Acts as the glue between the workflow engine and the notification bridge. When a \doxylink{classWorkComponent}{Work\+Component} changes state, this observer is notified, checks if the state has actually changed (to prevent spam), and dynamically builds a Notice.

Triggered automatically by the \doxylink{classWorkflowSubject}{Workflow\+Subject} when a state change occurs. 

Reacts to state changes by composing and sending notifications.

It pulls the current state and payload from the subject (\doxylink{classWorkItem}{Work\+Item}). If the state is different from {\ttfamily last\+State}, it instantiates {\ttfamily \doxylink{classResultNotice}{Result\+Notice}} objects, injecting the appropriate channels and sending them.
