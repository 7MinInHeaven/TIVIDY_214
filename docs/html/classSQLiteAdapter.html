Detailed Description

Adapter in the Adapter pattern and ConcreteStrategy in the Strategy pattern for SQLite.

Adapts the low-level SQLiteAPI (Adaptee) to the ExternalDatabase (Target) interface so DatabaseObserver can persist and retrieve workflow records locally in a .db file
